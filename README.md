# googlesearch

Projekt napodobuje stránku Google Search a obsahuje:

- `index.html` – základní vyhledávání
- `images.html` – vyhledávání obrázků
- `advanced.html` – rozšířené vyhledávání
- `forms.html` – ukázky HTML formulářových prvků
- `citace.md` – použité zdroje a prompty

Každá stránka obsahuje odkazy na validaci HTML a CSS, citace a portfolio.
